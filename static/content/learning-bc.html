BC prefers Compliant and Damped Controllers.

Our experiments across multiple manipulation tasks show that offline imitation learning is highly sensitive to the choice of controller gains. Policies trained with compliant, overdamped gains consistently achieve the highest success rates — often outperforming stiff-gain counterparts by over 30%.

Generating Gain-Dependent Demonstrations

Offline imitation learning distills a dataset of state-action pairs $\mathcal{D}(s, a)$ into a predictive policy $\pi(a|s)$. When using position targets as the action representation, the low-level controller gains $\mathbf{K}$ (stiffness $\mathbf{K}_p$ and damping $\mathbf{K}_d$) implicitly affect this learning process by altering the underlying state transition dynamics $p(s'|s, a)$. Understanding this relationship requires multiple datasets collected under multiple gain configurations:

How We Built These Datasets

Desired Attributes. As you saw above, the key property we need is for datasets to share a common gain-invariant state distribution $p^{\star}(s)$ (the robot follows the same motion) while exhibiting distinct action distributions $p(a; \mathbf{K})$ induced by each gain configuration. This isolation is critical: if both states and actions varied with gains, we couldn't determine whether learning differences stem from the action distribution or from seeing different robot behaviors.

same $p^{\star}(s)$,   different $p(a; \mathbf{K})$

Can't we just collect separately for each gain? A naive approach of collecting separate demonstrations under each gain setting fails to achieve this: the resulting datasets would differ in both state and action distributions due to different closed-loop dynamics and inherent stochasticity in the collection process (e.g., varying initial conditions, environmental randomness, human demonstrator variability). This conflation makes it difficult to isolate how gains affect learning. What we prefer instead is a method that produces nearly identical state trajectories across gain settings while varying only the actions represented as position targets.

Torque-to-Position Retargeting (TPR). We achieve this through a two-stage dataset generation procedure. First, we generate demonstration trajectories for each task at high frequency (500Hz) using torque commands as the gain-agnostic action representation. We then apply a position-command-retargeting method to convert these torque trajectories into position targets for arbitrary $(\mathbf{K}_p, \mathbf{K}_d)$ settings:

$\mathbf{q}_{\text{des}}(t) = \mathbf{q}(t) + \mathbf{K}_p^{-1}\left(\boldsymbol{\tau}(t) + \mathbf{K}_d \dot{\mathbf{q}}(t)\right)$

where $\boldsymbol{\tau}(t)$, $\mathbf{q}(t)$ and $\dot{\mathbf{q}}(t)$ are the torque command, joint position, and joint velocity from the original 500Hz torque control demonstration, respectively. Finally, for each gain configuration, we replay the retargeted position commands at the desired policy frequency (50Hz) using zeroth-order holding and save only the successful rollouts. This ensures that our datasets $\mathcal{D}(s, a; \mathbf{K})$ capture the same task outcomes across different controller settings while maintaining the distinct action distributions induced by each gain profile. We conduct this entire process in simulation to ensure controlled experimental conditions.

Gain-Dependent BC Training

With datasets $\mathcal{D}(s, a; \mathbf{K})$ in hand—each sharing the same state distribution but differing only in their action distributions—we can now directly measure how gains affect both learnability and performance. The interactive widget below provides two complementary views: the heatmap on the right encodes the task success rate for each $(\mathbf{K}_p, \mathbf{K}_d)$ configuration (darker = higher success), while clicking a cell loads its training loss curve on the left. Two findings stand out across all tasks:

  1. Compliant, overdamped gains win. The upper-left region of the grid (low $\mathbf{K}_p$, moderate–high $\mathbf{K}_d$) consistently achieves the highest task success rates.
  2. Lower training loss ≠ better policy. Stiff gains (lower-right region) tend to yield lower training loss—the policy fits the demonstrations more easily—yet produce worse task performance. The smooth, near-linear action distributions induced by stiff controllers happen to be easier for a network to regress, but the resulting policies fail where it counts.
