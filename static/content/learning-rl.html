RL can discover solutions for all gain settings.

Unlike behavior cloning, reinforcement learning is robust across all gain regimes — but only when hyperparameters are tuned to match. The dynamics induced by different gains effectively change the MDP the agent is solving, so learning rates, entropy coefficients, and reward scales need to be adjusted accordingly.

In our experiments, RL policies achieved comparable final performance across compliant, critically damped, and stiff settings, provided we swept over compatible hyperparameter ranges for each regime.
