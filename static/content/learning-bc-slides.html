BC prefers Compliant and Damped Controllers.

Our experiments across multiple manipulation tasks show that behavior cloning is highly sensitive to the choice of controller gains. Investigating this relationship starts with generating datasets with different gain settings.

Generating Gain-Dependent Demonstrations

Behavior cloning distills a dataset of state-action pairs $\mathcal{D}(s, a)$ into a predictive policy $\pi(a|s)$. When using position targets as the action representation, the low-level controller gains $\mathbf{K}$ (stiffness $\mathbf{K}_p$ and damping $\mathbf{K}_d$) implicitly affect this learning process by altering the underlying state transition dynamics $p(s'|s, a)$. Understanding this relationship requires multiple datasets collected under multiple gain configurations:

$\mathcal{D}(s, a; \mathbf{K})$

Desired Attributes. The key property we need is for datasets to share a common gain-invariant state distribution $p^{\star}(s)$ (the robot follows the same motion) while exhibiting distinct action distributions $p(a; \mathbf{K})$ induced by each gain configuration. This isolation is critical: if both states and actions varied with gains, we couldn't determine whether learning differences stem from the action distribution or from seeing different robot behaviors.

same $p^{\star}(s)$,   different $p(a; \mathbf{K})$

Can't we just collect separately for each gain?

A naive approach of collecting separate demonstrations under each gain setting fails: the resulting datasets would differ in both state and action distributions due to different closed-loop dynamics and inherent stochasticity in the collection process. What we prefer instead is a method that produces nearly identical state trajectories across gain settings while varying only the actions represented as position targets.

Torque-to-Position Retargeting (TPR). We achieve this through a two-stage procedure. First, we generate demonstration trajectories for each task at high frequency (500Hz) using torque commands as the gain-agnostic action representation. We then apply a position-command-retargeting method to convert these torque trajectories into position targets for arbitrary $(\mathbf{K}_p, \mathbf{K}_d)$ settings:

$\mathbf{q}_{\text{des}}(t) = \mathbf{q}(t) + \mathbf{K}_p^{-1}\left(\boldsymbol{\tau}(t) + \mathbf{K}_d \dot{\mathbf{q}}(t)\right)$

where $\boldsymbol{\tau}(t)$, $\mathbf{q}(t)$ and $\dot{\mathbf{q}}(t)$ are the torque command, joint position, and joint velocity from the original 500Hz torque control demonstration, respectively. For each gain configuration, we replay the retargeted position commands at the desired policy frequency (50Hz) using zeroth-order holding and save only the successful rollouts.

Gain-Dependent Training

With datasets $\mathcal{D}(s, a; \mathbf{K})$ in hand, we directly measure how gains affect both learnability and performance. The heatmap encodes task success rate for each $(\mathbf{K}_p, \mathbf{K}_d)$ configuration (darker = higher success), while clicking a cell loads its training loss curve.

  1. Compliant, overdamped gains win. The upper-left region (low $\mathbf{K}_p$, high $\mathbf{K}_d$) consistently achieves the highest success rates.
  2. Lower training loss ≠ better policy. Stiff gains yield lower training loss yet worse task performance.
